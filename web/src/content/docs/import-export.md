# Import/Export

<br />

## Export
You can export website comments in your websites settings.
  1. Click the website you want.
  2. Go to the settings tab
  3. In the general tab find "Data export"
  4. Click Download export

This will give you a JSON file with your comments and widgets that you can you to import back into PlopKit

<br />

## Import
To import go back to the home dashboard and click "Import Site". Fill in the required fields and import the PlopKit JSON file and your website will be setup with all the comments and widgets that was on that JSON file.
