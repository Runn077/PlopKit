# Widget Customization

![Widget customization panel](/docs/widget-customization.png)

Every widget can be restyled from the Customize tab in your website. No CSS or code required. Changes are scoped per-website.

<br />

## What you can customize

- **General:** font family (for both the UI and comment body separately), text color, accent color, divider color, widget background, corner radius, and padding

- **Input Area:** background, text color, border color, the post button's background/text/radius, and input padding

- **Comment Card:** background, text color, corner radius, and padding

- **Reply Card:** background, text color, quote-accent color, corner radius, and padding

- **Badges & Delete(Pinned, Owner and delete button):** the delete button color, and the owner/pinned badge colors

- **Toast(message that appears after you click post):** background, text color, and corner radius for notification toasts
