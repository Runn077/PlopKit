# Moderation

## Comments

![Widget comment moderation panel](/docs/moderation-comments.png)

The Comments tab shows the full list of comments (approved and visible). From here you can pin, delete comments, and respond to a comment with the owner padge.

<br />

## Pending

![Widget pending moderation panel](/docs/moderation-pending.png)

The Pending tab contains comments that require moderator review before they are publicly visible on the comment section. You are able to approve or reject a comment. The comments in this tab expire in 30 days. You are also able to auto approve if you don't feel the need to moderate every comment.

<br />

## Recently deleted

![Widget deleted moderation panel](/docs/moderation-deleted.png)

The Recently deleted tab stores comments that were deleted by you and is no longer visible in the public comment section. The comments in this tab is deleted in 7 days. You are able to permenantly delete the comments in this tab or restore them.

<br />

## Filter

![Widget comment moderation panel](/docs/moderation-filter.png)
The Filter tab is located in the websites dashboard, not the widgets. You are able to censor certain words here or you can auto reject comments that have those certain words.
